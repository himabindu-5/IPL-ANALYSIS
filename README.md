# IPL Match and Player Performance Analytics

## Project Objective
This project analyzes IPL match and ball-by-ball data to identify team performance, batting performance, bowling performance, toss impact, powerplay trends, and death-over performance.

## Tools Used
- Python
- Pandas
- Matplotlib
- MySQL
- MySQL Workbench
- Jupyter Notebook

## Dataset
- matches.csv
- deliveries.csv

## Analysis Performed
- Data cleaning and missing-value analysis
- Team-wise match wins
- Toss impact on match results
- Top run scorers and strike rates
- Most fours and sixes
- Top wicket takers
- Powerplay performance
- Death-over performance
- Player of the Match analysis
- Venue-wise match analysis
- SQL-based validation queries

 ## Key Insights
[V Kohli] scored the most runs in the dataset.
[Mumbai Indians] won the highest number of matches with 144 wins
Toss winners won approximately [50.83]% of matches.
[YS Chahal] took the most wickets.
[AB de Villiers] received the most Player of the Match awards with [25] awards.
[S Dhawan] scored the most runs during powerplay overs with [3415] runs.
[MS Dhoni] scored the most runs in death overs with [2786] runs
